# GitSense

GitSense is a GitHub Repository Health & Learning Analyzer.

It analyzes a GitHub repository and provides insights about:

- Repository structure
- README quality
- Commit activity
- Documentation
- Code organization
- Project health
- Possible improvements

## Project Goal

The goal of GitSense is to help developers understand the strengths
and weaknesses of their GitHub projects and improve them step by step.

## Planned Technologies

- Python
- Git
- GitHub API
- Data Analysis
- AI/LLMs
- Streamlit
